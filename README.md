# HTML Semantic Elements

## Explanation

This program demonstrates semantic elements in HTML.

Semantic elements clearly describe the purpose of different parts of a webpage.

The webpage is divided into header navigation main content sections article aside and footer.

## Problem Statement

Create an HTML webpage using semantic elements to organize the content into meaningful sections.

## Features

- Uses semantic HTML elements
- Creates a webpage header
- Creates a navigation area
- Organizes main content
- Uses sections and articles
- Includes additional information using aside
- Creates a footer

## How It Works

The <header> element contains introductory content.

The <nav> element contains navigation links.

The <main> element contains the main content of the webpage.

The <section> element divides the page into different sections.

The <article> element contains independent content.

The <aside> element contains additional information.

The <footer> element contains footer information.

## Attributes Used
